專案結語與學習心得

透過這次線上課程平台的開發，我不僅將課堂上學習的 Java 程式設計知識實際應用於專案中，也更加了解一個完整系統從規劃、設計、開發到測試的過程。本專案以 Spring Boot 建立課程管理與選課系統，將功能分為 Course Service 與 Enrollment Service 兩個微服務，實作教師登入、課程新增、修改與刪除，以及學生查詢課程、加選與退選等功能，並透過 WebClient 串接不同服務，讓各項功能能夠互相配合。此外，我也學習運用 RESTful API、物件導向程式設計、Collections、例外處理及 File I/O 等技術，將課程資料與選課紀錄儲存於文字檔案中，並透過資料驗證與錯誤訊息處理，提升系統的完整性與穩定性。

在開發過程中，我也體會到實際撰寫程式並不只是讓功能順利執行，更需要考慮資料的一致性、不同服務之間的溝通，以及使用者操作時可能發生的錯誤。例如，選課時必須避免重複選課及超過課程人數上限，退選時也需要確認學生是否確實選過該課程。遇到登入資訊顯示錯誤、資料儲存異常及中文編碼問題時，我也學會透過檢查程式碼、分析執行結果與逐步測試來找出問題，進一步培養除錯能力與解決問題的能力。

這次專案經驗對未來的學習與職涯發展具有很大的幫助。透過實際開發，我對後端程式設計、前後端串接、API 設計及微服務架構有了更具體的認識，也了解到團隊合作時，清楚的系統規劃、功能分工與程式整合都十分重要。未來無論是繼續學習軟體開發、參與更大型的資訊系統專案，或是進入職場從事程式設計相關工作，這次累積的實作經驗都能成為重要的基礎，幫助我更有系統地分析需求、設計功能、處理問題，並持續提升自己的程式能力與專案開發能力。
